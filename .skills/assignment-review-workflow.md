# 作业重审技能

**Skill Name:** 作业重审 (Assignment Re-review)  
**Description:** 将个人过去的学术作业在多年后用AI重新审视，通过多轮迭代产出更成熟的新作品。核心价值在于时间的纵深——对比当年的自己和今天的自己。

## 何时使用

- 用户有过去（数年）的学术作业想要重做
- 用户希望系统地对比"当年写的"和"今天能写出的"
- 用户想要借助AI进行多维度拓展和迭代

## 工作流程

### 第一阶段：初始设置

1. **获取原始文件**：读取用户提供的原始作业文件（docx/txt/pdf等）
2. **个人信息脱敏**：将所有个人姓名替换为**|姓名A|**，学号替换为**|学号|**，保留学校/机构/班级名称
3. **建立目录结构**：


作业重审/
├── 001-作业简称/
│   ├── images/
│   ├── 001-作业简称-原始脱敏-v1.md
│   ├── 001-作业简称-脱敏记录-v1.md
│   ├── 001-作业简称-分析笔记-v1.md
│   ├── 001-作业简称-修改意见-v*.md
│   ├── 001-作业简称-修改过程-v*.md
│   ├── 001-作业简称-新作品-v*-A.md   (学术版)
│   ├── 001-作业简称-新作品-v*-B.md   (非学术版)
│   └── 001-作业简称-对照注-v1.md
├── 002-作业简称/
├── 003-作业简称/
└── ...


### 第二阶段：分析与初稿

1. **分析笔记**：对原作业做结构拆解、优缺点分析、可拓展方向识别
2. **确定版本方向**：每份作业产出两个方向的版本——
   - **A版（学术版）**：科研论文语体，引用规范，概念严谨
   - **B版（非学术版）**：活泼叙事风格，口语化，比喻生动
3. **编写修改意见**：明确本轮修改方向和具体改动
4. **生成新作品**：按修改意见产出实际内容
5. **编写修改过程**：记录从上一版到本版的变化

### 第三阶段：迭代深化

每轮迭代的深化方向：

| 轮次 | 学术版深化方向 | 非学术版深化方向 |
|------|--------------|----------------|
| v1 | 基础框架+参考文献 | 基础叙事 |
| v2 | 方法论/理论分析 | 加入反思和张力 |
| v3 | 行业案例/国际比较 | 具体故事案例 |
| v4 | 综合评估+改革建议 | 个人收束+温暖结语 |

迭代原则：
- 每轮修改意见指向下一轮的修改方向
- 每轮修改过程记录从上一轮到本轮的变化
- 所有旧版本 **不删除、不覆盖**

### 第四阶段：可视化和收尾

1. **生成图表**：为最终版本生成PNG图片（如知识图谱、流程图、数据对比图、开头段落对比图）
2. **对照注**：撰写作业对照反思，对比当年的自己与今天的自己
3. **路径说明**：记录过程中遇到的技术问题和解决方案

## 文件命名规则

**文件夹命名**：[序号]-[作业简称]
- 序号：三位数递增（001, 002, 003...）
- 简称：2-4个汉字概括作业主题

**文件命名**：[序号]-[作业简称]-[产出类型]-v[版本号][-子版本].md
- 产出类型：七种固定类型（见下方表格）
- 版本号：v1, v2, v3, v4...
- 子版本（仅新作品）：A=学术版, B=非学术版

**图片命名**：[图片描述].png 存于作业目录下的 images/ 文件夹

### 七种产出类型说明

| 类型 | 说明 |
|------|------|
| 原始脱敏 | 原始作业经脱敏后的版本 |
| 脱敏记录 | 脱敏信息对照表 |
| 分析笔记 | AI对作业的分析和拓展方向 |
| 修改意见 | 当前版本的修改方向和建议 |
| 修改过程 | 本次修改具体做了什么、为什么 |
| 新作品 | 重新完善后的最终版本 |
| 对照注 | 当年的自己和今天的自己的对话 |

## 编码注意事项

⚠️ **经验教训**：在PowerShell环境下处理中文内容时，需注意：
- 避免在字符串中使用中文左右引号（" "），它们可能被误读为ASCII双引号
- 使用 「」 代替中文引号，或用Unicode转义 \u201c \u201d
- 在生成图片时使用Windows内置字体 msyh.ttc（微软雅黑）支持中文
- 长内容的Python脚本应写入.py文件后再执行，而非通过-c参数传递

## 图片生成规范

图片使用Pillow库生成：
- 主字体：微软雅黑（C:\Windows\Fonts\msyh.ttc）
- 背景色：(248, 250, 252)
- 标题字体大小：22-30pt，正文字体大小：14-18pt
- 边框圆角：6-8px
- 配色方案：不同功能区域使用不同的蓝色/绿色/橙色系

## AGENTS.md 配置

项目根目录建议放置 AGENTS.md，包含：
1. 项目定位和核心价值
2. 敏感信息范围与脱敏格式
3. 交流风格规范
4. 文件命名与版本管理规则
