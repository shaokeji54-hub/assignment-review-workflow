# Assignment Review Workflow v1.1.0

A personal workflow for revisiting past academic assignments with AI, producing mature new works through iterative refinement.

## v1.1 Key Improvements

1. **File Classifier** — Categorize files before processing (essay, engineering design, lab report, template, scanned)
2. **Quality Anchors** — Minimum standards per version to prevent quality degradation in batch operations
3. **Processing Mode Selection** — Choose full-coverage, curated-depth, or mixed-batch at task start
4. **Optional Visualization** — Assessment criteria to decide when a chart adds genuine value
5. **Group Assignment PII** — Multi-person desensitization rules with cross-file consistency
