# Assignment Review Workflow

A personal workflow for revisiting past academic assignments with AI, producing mature new works through iterative refinement.

## Repository Contents

- `.skills/assignment-review-workflow.md` — Reusable workflow documentation
- `AGENTS.md` — Project workflow rules and privacy guidelines
- `CHANGELOG.md` — Version history and release notes

## Workflow Overview

1. **Read & Analyze** — Desensitize personal info, analyze structure
2. **Dual-version creation** — Academic (A) + Non-academic (B) versions
3. **Multi-round iteration** — v1 framework -> v2 deepening -> v3 cases -> v4 synthesis
4. **Visualization** — Knowledge graphs, comparison charts, data diagrams
5. **Reflection notes** — Document "then vs now" comparison
